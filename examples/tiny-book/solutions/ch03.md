# Chapter 3 Solutions

## Exercise Solutions

1. The config file:

   ```toml
   default_method = "aeropress"
   default_ratio = 14
   default_temp = 85
   ```

   The shortest command supplies only the two required options:

   ```bash
   brewlog add --bean "Ethiopia Guji" --dose 17
   ```

   It records an AeroPress brew at 85 degrees Celsius with 238 grams of water (17 times 14).

2. With no `config.toml`, Brewlog uses the built-in defaults: method `v60`, water 288 grams (18 times the default ratio of 16), and 93 degrees Celsius.

3. 96 degrees. The command-line option comes first in the precedence order, so it beats the `default_temp` value in `config.toml`.

4. The `~/.brewlog/` journal is listed, because `--journal` wins over `BREWLOG_JOURNAL`. Brewlog reads `config.toml` from the journal folder, so the `config.toml` in `~/.brewlog/` applies.

5. `default_tmp` is a typo for `default_temp`. Brewlog stops on any key it doesn't recognize and reports "invalid config key". Rename the key to `default_temp`.

6. The `units` setting affects only display. Imperial shows ounces and Fahrenheit, but Brewlog still stores grams and Celsius, so the journal contents are the same in either mode.

## Quiz Answers

1. In the journal folder (`~/.brewlog/` by default, or the folder chosen with `--journal` or `BREWLOG_JOURNAL`).
2. `16`. It stands in for `--water`: when `--water` is omitted, water is `dose * default_ratio`.
3. b. Command-line option, environment variable, `config.toml`, built-in default.
4. Brewlog rejects it. `rating_scale` is fixed at 5 in this version.
5. False. Imperial changes the display only; Brewlog still stores grams and Celsius.
6. `NO_COLOR`.
7. It skips the line with a warning that names the line number and loads the rest of the journal.
8. The capitalization of the name. Bean names are case-sensitive, so the name must match the registered one exactly.
