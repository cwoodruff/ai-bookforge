# Chapter 1 Solutions

## Exercise Solutions

1. Run `pip install brewlog`, then `brewlog --version`. The version string is whatever your install reports; the exact text isn't specified in the source material. Your Python version must be 3.10 or later.

2. Brewlog records a bean's name, its roaster, and its roast date. For example: a name you choose for the bag, the roaster printed on the label, and the roast date printed on the label.

3. 288 / 18 = 16, so the first recipe is 1:16. 300 / 20 = 15, so the second is 1:15. The 1:15 recipe is stronger, because it uses less water for each gram of coffee.

4. French press is `french-press` (lowercase, with a hyphen). Moka pot is `moka`. These are the names as the source material lists them; it doesn't say how Brewlog handles other spellings.

5. The journal holds three lines for that brew: the original and two later revisions. All three share the same id, and each later one has a higher `rev` number. Nothing was rewritten in place. Brewlog shows the latest revision, the one with the highest `rev`.

6. Answers vary. A good plan keeps the method (`v60`), bean, dose, water weight, and all but one other variable fixed for all seven days, and changes only the chosen variable (for example grind) in small steps from day to day.

## Quiz Answers

1. Home brewers change one variable at a time and then forget what they changed. Brewlog keeps a plain-text journal of every brew so they can compare results later.
2. Python 3.10 or later.
3. One JSON object per brew.
4. `chemex`. Brewlog's methods are `v60`, `aeropress`, `french-press`, `espresso`, and `moka`.
5. It divides the water weight by the dose, and shows the result in the form `1:16`.
6. It validates your input, fills in defaults from `config.toml`, computes the ratio, and appends one line to `journal.jsonl`.
7. False. Edits append a new version of the brew with the same id and a higher `rev` number; nothing is rewritten in place.
8. The latest revision.
