# Chapter 2 Solutions

## Exercise Solutions

1. Register the bean with a name and roaster, leaving out `--roasted`, which is optional. For example:

   ```bash
   brewlog bean add "Colombia Huila" --roaster "Northside"
   brewlog add --method v60 --bean "Colombia Huila" --dose 15 --water 250 --rating 3
   brewlog list --bean "Colombia Huila"
   ```

   The list shows only the one brew, because `--bean` filters to that bean.

2. All three are rejected. Brewlog rejects a rating outside 1 to 5, a dose of zero or less, and an unknown bean name. The source material ties exit code 2 to the unknown bean name; it doesn't state the exit code for the other two, so record what you observe.

3. `brewlog best` shows the highest-rated brew for each method used with that bean. With two methods, you get one line per method.

4. Pass the same `--journal PATH` to each command in the scratch journal:

   ```bash
   brewlog bean add "Test Bean" --roaster "Northside" --journal /tmp/brewlog-test
   brewlog add --method v60 --bean "Test Bean" --dose 15 --journal /tmp/brewlog-test
   brewlog list
   ```

   The last command uses the default `~/.brewlog/` folder, so the test brew doesn't appear.

5. Run:

   ```bash
   brewlog export --format csv > brews.csv
   brewlog export --format json > brews.json
   ```

   Export always writes the latest revision of each brew, so the edited brew appears once with its new rating.

## Quiz Answers

1. `--bean` and `--dose`.
2. It uses `dose * default_ratio`, where `default_ratio` comes from config (see Chapter 3).
3. (b) `--dose 0`. A dose of zero or less is rejected. `--grind` accepts any number, a rating of 5 is in range, and `--temp` has no stated limit.
4. Exit code 2.
5. 20 brews, newest first.
6. The most recent one. Ties go to the most recent brew.
7. Nothing. It appends a new revision of the brew with the changed fields; the original line stays in the journal.
8. `csv` and `json`. Export always writes the latest revision of each brew.
